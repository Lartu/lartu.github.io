Ongoing Projects

This is a list of projects I'm currently working on, and projects I've worked on in the past. It's not comprehensive. I started it on November 22, 2026, when I felt a burst of inspiration hit me while surfing around Gemini. Isn't it great when that happens? It makes me feel so alive.

Stuff I am currently working on

This is stuff I'm actively working on. A link might be provided with each project, should they be public; otherwise it means they're either private or that they haven't reached enough maturity to be published yet.

  • Eterspire, an MMORPG and the best thing I've ever built. This is also my main job.
  • LartuNet, my personal website (this very site!). I actively maintain it using Makompile (see below), especially this list and the book club one. From time to time I change the way it looks and behaves, but it is still my personal corner of the internet.
  • PolyComposer, name tbd though. A graphical engine for making games for modern and old systems alike. At the moment it supports modern and classic macOS, PSP, PlayStation 2, web, iOS and Android.
  • Axonote, name subject to change. A Telegram Saved Messages-inspired note taking app for iOS and macOS.
  • Nariscope, a native Gopher browser for macOS.

Stuff I've worked on

This is a list of projects I've worked on, that were previously listed here, or that I felt like listing, but that I'm not actively working on at the moment. I might go back and revisit them in the future though!

  • The LDPL Programming Language, a programming language inspired by COBOL that transpiles to C++. It has quite a rich set of features and is stable, but since the advent of AI, I haven't really felt like working on it.
  • Makompile, a markdown-like website-making tool, used to compile this very site. It's not abandoned, but I haven't touched it for a while. I actively use it, though.
